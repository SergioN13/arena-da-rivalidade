📁 Como funciona esta galeria

O Firebase continua responsável pelo placar e ranking da Arena.
A galeria utiliza o GitHub para armazenar as imagens.

Para adicionar uma nova foto:

1. Coloque a imagem dentro da pasta: fotos/ 2. Exemplo: fotos/desafio-004.jpg 3. Cadastre a imagem na lista fotos dentro deste arquivo.

4. Faça commit e push para o GitHub.
5. O GitHub Pages atualizará a galeria.

📸 Adicionar momento

📌 Importante

Este botão não envia a foto para um servidor ou para o Firebase.

A foto deverá ser colocada manualmente na pasta fotos/ do GitHub.

Depois você cadastra o caminho da imagem na lista de fotos deste arquivo.
